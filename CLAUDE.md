# Project instructions

## YD Perfums social content — Hebrew by default

All social copy for YD Perfums is written **in Hebrew by default**: Instagram
captions, TikTok captions, YouTube Shorts titles and descriptions, CTAs, hooks,
and hashtags (only when appropriate).

- Write natural, native Hebrew, never translated-sounding.
- Tone: direct, elegant, confident, niche. No corporate wording.
- Keep English only for the brand name (**YD Perfums**), product names, and
  selected hashtags (e.g. `#YDPerfums`).
- Use another language only when the user explicitly asks, and only for that
  specific post. The next post goes back to Hebrew.
- This applies to drafts saved through Zernio and to copy written for
  OpenArt-generated media.

Before writing any social post, follow the full guide in
[`brand/voice-hebrew.md`](brand/voice-hebrew.md). Machine-readable defaults
are in [`brand/social-config.json`](brand/social-config.json).

## YD Perfums visual design system

All new educational posts, carousel covers, inner carousel slides and
highlight covers follow [`brand/design-system.md`](brand/design-system.md):
luxury, minimal, warm cream background, thin gold frame, refined serif
headlines, thin spaced secondary type, centered layout, lots of negative
space, and a soft centered YD watermark. No loud, colorful or cluttered
designs. Reference images live in `brand/design/references/`; use them for
style only and never copy their text unless asked. Render designs with
`brand/design/render.js`.
